# Broquer

Primera etapa de una reconstrucción nueva, independiente del código anterior.

- `app/`, `components/broquer/`: experiencia web móvil primero y proxy HTTP.
- `backend/`: API Python/FastAPI, migraciones PostgreSQL, pruebas y base de worker.
- `shared/`: catálogo declarativo compartido.
- `docs/LOGICA.md`, `docs/DISENO.md`: documentos originales.
- `docs/ESTADO.md`: integración, alcance efectivo, bloqueos y trabajo pendiente.

**F0 iniciada, no completada.** La publicación de Sites es una demo visual de solo lectura para datos de negocio; solo las favoritas se guardan como preferencia local. No hay Supabase ni Railway de producción conectados. No habilitar registros reales hasta cerrar los pendientes y pruebas de F0.
